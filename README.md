# Portlaoise Social Board Games

Basic npm template for the Portlaoise Social Board Games project.

## Quick start

1. Install dependencies

   npm install

2. Start the server

   npm start

3. Dev (auto-reload)

   npm run dev

## API

- GET /api/health - basic health check
- GET /api/games - sample list of games

## Notes

This is a minimal starter template. Add routes, a frontend, tests, and CI as needed.
